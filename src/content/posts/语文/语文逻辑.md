# 主观题

## 一、核心逻辑：分析题干+回答问题（+情感）
- 分析题干：有深层含意才分析
- 回答问题：先分类，再回答
- 注意：
  1. “题干”不仅指题目，还包含题目中包含/引用/提及的原文
  2. 多练真题

---

## 二、语文大题答题范式（除语用外）
1. **分析题干**：若存在表层和深层含义，那就都写上去，不用纠结简洁性
2. **回答问题**：按题型分类（how/why），优先原文对应（若不是why则为后者）

### 题型分类
#### ① 原文对应题
- 分析题干（表层+深层）→ 仅分析情感、以笔题
- 回答问题：
  1. （对应要点）
  2. （对应要点）
  3. （对应要点）
  4. （对应要点）
  5. 情感
- 每一点分得开、答得全（写得下）
- 分析方法：**拆分+原句对应**（拆成原句的下一层级：段→句→词），拆成几个不同部分，每一部分都对应原文去答

#### ② 手法题（how）
- 直接：手法（特色）
  - 词：拟人、比喻……
  - 句：长短句、整散句
  - 段：夹叙夹议
- 间接：手法+语言艺术
  - 语言特色 → 语言风格
  - 语言特色（手法/修辞）：
    - 拟人、比喻 → 生动形象
    - 用词 → 典雅精炼 → 有诗意
    - 句式 → 丰富多变
    - 段落 → （结构相关）
    - 语言风格 → （整体风格）

#### ③ 作用题（why）
1. **结构**：（承上启下、总领全文、总结上文等）
2. **内容**：“旨环人情” + 读者 + 叙述
   - 叙述（在三点中）：
     - 视角：无人、小孩、动物……
     - 节奏：缓、急
     - 顺序：顺叙、倒推、补叙
- 注：对论述类文本的说明：
  - 作用题：
    - 论点 → 突出强调
    - 论据 → 丰富翔实
    - 论证：
      - 逻辑严密、流畅
      - 结构紧凑、脉络分明
      - 读者兴趣

# 客观题（选择题）
1. **根本逻辑**：
   - 无法证明全对就对
   - 不扣细小的细枝末节
   - 自觉逻辑
2. **分析过程**：
   3. 找每个选项中的**易错命句**，优先比对对照
   4. 易错命句看配对，再判断易对命句
   - 注：原文没说就判断为**或然属性**（易错、易对）
     - 易错：强因果逻辑（只有…才…；只要…就…；之所以…是因为）、否定（没有、不是）、目的性（为了…；以…）、拉扯策（A比B更…，原文中无说明）
     - 易对：有可能、基础、重要、存在（都不好判断，作为证明错）
